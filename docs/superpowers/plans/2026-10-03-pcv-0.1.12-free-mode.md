# PCV 0.1.12 Free Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `docs/superpowers/specs/2026-10-03-pcv-0.1.12-free-mode-design.md`. A "free scene" takes the nearest six eligible NPCs as members at activation, with the opener chosen by name, then the player's target, then the nearest.

**Architecture:**
- A pending free scene is `scene_mode: 'pair'` with `free: true` and no members.
- At activation `pcv_begin_request` picks the members from a distance-ordered candidate list that `pcvBeginResolvedScope` builds from the input's routing snapshot. The result is a normal 0.1.11 group config (`actor_ids` of up to 6, `opener: 'auto'`, `free: true`), so the 0.1.11 routing applies unchanged.
- The opener rule gains the player's direct target (CHIM's decoded `requestRoutingSnapshot.listener` when `target_mode === 'direct'`) and a `nearest` fallback for free scenes.

## Verified before planning (CHIM source on the clone)

/** Members of a free scene: the first $cap candidate IDs (nearest first) that are strictly eligible. */
function pcv_free_select_members(array $candidateOrder, array $eligible, int $cap = PCV_FREE_MAX_MEMBERS): array
{
    $members = [];
    foreach ($candidateOrder as $id) {
        $id = (string)$id;
        if (array_key_exists($id, $eligible) && !in_array($id, $members, true)) {
            $members[] = $id;
            if (count($members) >= $cap) {
                break;
            }
        }
    }
    return $members;
}
