# PCV 0.1.11 Group Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `docs/superpowers/specs/2026-10-03-pcv-0.1.11-group-mode-design.md`: 2–4 NPC scenes with an auto opener, partial start, mid-scene drop and pair compatibility.

**Architecture:**
- Non-solo scenes keep the internal mode name `pair` and the `actor_a`/`actor_b` fields, which now mirror the first two members.
- An ordered member list `actor_ids` (2–4) and `opener` (`auto` or a member ID) are added. A stored config without `actor_ids` is the legacy two-member pair.
- `pcv_config_actor_ids()` becomes the single membership seam, and resolved scopes gain `members` (names) and `profiles` (name → profile ID).
- PCV already forces CHIM's `tight` rechat mode, so the NPC addressed by a line speaks next. Widening the listener enum from "the counterpart" to "any other member" lets CHIM route group turns with no further rechat logic.

- PHP 8.2 CHIM hooks.
- Plain-PHP fixtures run through `scripts/live-test/run-php-tests.sh` in `DwemerAI4Skyrim3-test`.
- Node test `tests/ui_refresh_check.mjs`.
- Python simulator.

## Verified before planning (CHIM source on the clone)

- `context_pre.php:40` sets `$GLOBALS['RECHAT_MODE'] = 'tight'` for every PCV scene. In `chimResolveServerSideRechatTarget`, tight mode's only candidate is `listener_hint`, filtered by `active_agents` and the conversation's people. The addressed member answers.
- Each chat row's `people` comes from `chimBuildDialogueEventPeoplePipe(turnPeople, speaker, listener)`, and `turnPeople` is PCV's scoped `CACHE_PEOPLE`. Set to the members, the witness list is exactly the members (checked again in the clone run).

```php
/**
 * Narrow a group config to the members present in $eligible (catalog ID => name). Legacy pairs and solo are
 * all-or-nothing and return null when anyone is missing. Returns ['config' => narrowed, 'dropped' => [ids]] or null.
 */
function pcv_group_narrow_config(array $config, ?array $eligible): ?array
{
    if (!is_array($eligible)) {
        return null;
    }
    $ids = pcv_config_actor_ids($config);
    $present = array_values(array_filter($ids, static fn($id) => is_string($id) && array_key_exists($id, $eligible)));
    if (!is_array($config['actor_ids'] ?? null)) {
        return count($present) === count($ids) ? ['config' => $config, 'dropped' => []] : null;
    }
    if (count($present) < 2) {
        return null;
    }
    $narrowed = $config;
    $narrowed['actor_ids'] = $present;
    $narrowed['actor_a'] = $present[0];
    $narrowed['actor_b'] = $present[1];
    if ($narrowed['opener'] !== 'auto' && !in_array($narrowed['opener'], $present, true)) {
        $narrowed['opener'] = 'auto';
    }
    return ['config' => $narrowed, 'dropped' => array_values(array_diff($ids, $present))];
}
```

```php
/** Opener for a group turn: earliest member named in the direction (full name, or unique first word), else picker, else first. */
function pcvGroupPickOpener(string $direction, array $members, ?string $pickerName): array
{
    $firstWords = [];
    foreach ($members as $name) {
        $word = strtok(trim($name), ' ');
        if (is_string($word) && $word !== '') {
            $key = pcv_scope_name_key($word);
            $firstWords[$key] = ($firstWords[$key] ?? 0) + 1;
        }
    }
    $best = null;
    foreach ($members as $name) {
        $patterns = [trim($name)];
        $word = strtok(trim($name), ' ');
        if (is_string($word) && $word !== '' && ($firstWords[pcv_scope_name_key($word)] ?? 0) === 1) {
            $patterns[] = $word;
        }
        foreach ($patterns as $pattern) {
            if (preg_match('/(?<![\p{L}\p{N}])' . preg_quote($pattern, '/') . '(?![\p{L}\p{N}])/iu', $direction, $m, PREG_OFFSET_CAPTURE) === 1) {
                $position = $m[0][1];
                $length = strlen($pattern);
                if ($best === null || $position < $best['position'] || ($position === $best['position'] && $length > $best['length'])) {
                    $best = ['name' => $name, 'position' => $position, 'length' => $length];
                }
            }
        }
    }
    if ($best !== null) {
        return ['name' => $best['name'], 'source' => 'named'];
    }
    if (is_string($pickerName) && in_array($pickerName, $members, true)) {
        return ['name' => $pickerName, 'source' => 'picker'];
    }
    return ['name' => $members[0], 'source' => 'first'];
}
```
