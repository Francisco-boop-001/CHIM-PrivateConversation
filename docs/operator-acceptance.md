# Operator acceptance checklist

**Development follow-up; manual checks not run.** This neither amends nor certifies published 0.1.7. Use a disposable CHIM server and database plus a separate test client/profile/save; never a live server or production database.

Record PCV version/install route, CHIM/server revision, client build, Mind Poisoning version/API and enabled state, and UTC start time. Back up test-server files/configuration, database, and client package/sync setup. Restore to a separate disposable target and confirm ordinary chat; if not tested, record **rollback unverified**.

For each check, record **PASS / FAIL / NOT RUN**, UTC time, versions/settings, observed behavior, and fixed event/outcome/reason codes from PCV **Operational logs** or Mind Poisoning diagnostics. Write `none` or `no matching log`; do not invent codes or include dialogue/audio. Missing diagnostics are not a pass.

1. **Ordinary baseline.** With no PCV scene armed, send an ordinary Standard input and observe the response. Expected: CHIM handles it normally. Record the response path and any PCV routing entry.

2. **Pair and bystanders.** Select eligible A/B, enable **Exclude the player**, set **Other NPCs** to **Exclude from this conversation**, click **Arm or update on next input**, and send an ordinary Standard direction about C. Expected: A starts; supported rechat may stay with A/B per CHIM settings, and direction is instruction, not Player speech. Repeat with **Present but silent**; it adds generic scenery, not silence from vanilla greetings. Record mode/speakers. This cannot prove private history, model compliance or physical privacy.

3. **Solo and optional opinion effect.** Select eligible **Reflecting NPC** A in **Solo reflection**, exclude the player, click **Arm or update on next input**, and send ordinary Standard direction for A to think aloud. Expected: one response, no automatic continuation. With compatible, enabled MP, a correlated `committed` or `zero_change` result passes; no opinion delta is required. A documented policy skip/rejection matching the recorded settings, or absent/incompatible MP, makes the effect subcheck **NOT APPLICABLE**—not proof of integration; record its fixed reason. With MP enabled, missing/mismatched ACK or final outcome, registry/provider error, or failed/unconfirmed persistence is **FAIL / investigate**. An error log does not pass the check. `reflection.output_registered` alone is not an opinion result; record PCV and MP outcomes separately.

4. **Second reflection after 60 seconds.** Use the first `reflection.output_registered` UTC time; after 61 seconds and before 600 seconds have elapsed, send a second distinct Standard direction with new material. Do not interrupt requests or manufacture a failure. With MP enabled, expect a second response, distinct registration tuple and its own outcome; without compatible MP, mark only the opinion subcheck **NOT APPLICABLE**. If the first was acknowledged, this tests repeat use. A distinct accepted registration while the first remains unclaimed is replacement evidence; the UI does not display lease status directly, so mark that subcase **NOT RUN** unless diagnostics establish it. Missing registration/ACK or operational error with MP enabled is **FAIL / investigate**, not a valid skip.

5. **END, including stale eligibility.** During an active scene, click **End now**, then send ordinary Standard input. Expected: scene ends immediately and input follows normal CHIM handling; in-flight work/audio may finish. Separately, if an actor naturally becomes stale/unavailable, wait until PCV shows it, click **End now** without refreshing/editing reports, then send ordinary input. Expected: END works and stale scene state does not hold the next request. Record presence status/reason and routing outcome; if staleness cannot occur naturally, mark **NOT RUN**.

6. **Disable and remove.** Record the install route. Disable/remove PCV from that source using its supported client/manager controls, then use CHIM Plugin Manager **Delete** for the server copy. Sync/reload once; confirm PCV stays absent and ordinary Standard chat works. Do not edit ledgers, migration rows, tables or files by hand. Delete does not undo MP opinions or prove DB rollback; END/uninstall do not cancel in-flight work/audio. Database restoration is separate and must use the tested backup procedure.

Keep the completed record with the exact tested versions and dates. A failure report should include the step, expected/observed behavior, fixed codes and bounded relevant logs, not a full private transcript. No successful checklist run should be described as a privacy guarantee or as proof for a different server/client revision.
